## バックエンド

| 分類 | 内容 | バージョン |
|---|---|---|
| 言語 | Java（最新LTS） | 25（Toolchain指定、実行時25.0.1） |
| フレームワーク | Spring Boot（最新安定版） | 4.1.0 |
| API形式 | REST API | - |
| データアクセス | Spring Data JPA | 4.1.0（内部でHibernate ORM 7.4.1.Finalを使用） |
| パッケージ管理 | Gradle（Gradle Wrapper使用） | 9.5.1 |
| ディレクトリ | `backend/` | - |

Javaバージョンは `build.gradle` の Toolchain 指定（`JavaLanguageVersion.of(25)`）で固定する。ローカルに指定バージョンのJDKが無い環境でもビルドできるよう、`settings.gradle` に Foojay Toolchain Resolver プラグインを導入し、初回ビルド時にGradleが自動で対応するJDKを取得する構成にしている。

## データベース

| 分類 | 内容 | バージョン |
|---|---|---|
| DBMS | PostgreSQL | 17（Dockerイメージ`postgres:17`、実行時17.11） |
| 接続 | `org.postgresql:postgresql`（JDBCドライバ）+ Spring Data JPA | JDBCドライバ 42.7.11 |
| ローカル環境 | Docker Compose（リポジトリ直下の `docker-compose.yml`）で起動。ホスト側ポートは5433（Postgres.appが使う5432との衝突を避けるため） | - |
| スキーマ管理 | 開発時は `spring.jpa.hibernate.ddl-auto=update` によるエンティティからの自動生成（雛形レベル。本格運用時はFlyway/Liquibase等の導入を検討） | - |

上記バージョンは2026-08-28時点でのインストール済みバージョン（`npm list` / Gradle依存関係キャッシュより確認）。最新かつ正確な値は `frontend/package.json` と `backend/build.gradle` を一次情報として参照すること。

接続情報は `backend/src/main/resources/application.properties` に設定する。DB名・ユーザー名・パスワードは `docker-compose.yml` と一致させる（開発用に `taskboard` / `taskboard` / `taskboard`）。ホスト指定は `localhost` ではなく `127.0.0.1` を使う（macOSでのIPv6優先解決による接続遅延を避けるため）。

## 開発ツール

| ツール | 用途 |
|---|---|
| Git / GitHub | バージョン管理・ソースコードのホスティング |
| npm | フロントエンドのパッケージ管理・スクリプト実行 |
| Gradle（Wrapper） | バックエンドのビルド・依存管理・実行（`./gradlew bootRun` 等） |
| Docker / Docker Compose | ローカルのPostgreSQL環境の起動・管理（`docker compose up -d` 等） |
| ブラウザ / IDEの開発者ツール | 動作確認・デバッグ |

## ディレクトリ構成

```
frontend/           … React + Vite製フロントエンド（npm管理）
backend/            … Spring Boot製バックエンド（Gradle管理）
docs/               … 要件定義の詳細ドキュメント
docker-compose.yml  … ローカルのPostgreSQL環境定義
```

フロントエンドとバックエンドを同一リポジトリ内で管理するモノレポ構成とする。
